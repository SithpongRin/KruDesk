# KruDesk — ជំនួយការគ្រូបន្ទុកថ្នាក់

**KruDesk** គឺជាកម្មវិធីគេហទំព័រ Offline-first ១០០% សម្រាប់គ្រូបន្ទុកថ្នាក់នៅប្រទេសកម្ពុជា។ កម្មវិធីនេះជួយគ្រូគ្រប់គ្រងបញ្ជីឈ្មោះសិស្ស បញ្ជីវត្តមានប្រចាំថ្ងៃ បញ្ជីពិន្ទុប្រចាំខែ/ឆមាស/ប្រចាំឆ្នាំ និងបោះពុម្ពកាតសិស្សផ្លូវការលើក្រដាស A4 ដោយមិនចាំបាច់មានគណនី (Login) ឬម៉ាស៊ីនមេ (Backend) ឡើយ។

---

## មុខងារសំខាន់ៗ

- **ផ្ទាំងដើម (Dashboard)**៖ សង្ខេបចំនួនថ្នាក់ ចំនួនសិស្ស (ប្រុស/ស្រី) អវត្តមានថ្ងៃនេះ សិស្សអវត្តមានច្រើនជាងគេប្រចាំខែទាំង ៣ នាក់ និងការរំលឹកបម្រុងទុកទិន្នន័យ (Backup)។
- **សិស្ស និងថ្នាក់**៖ បង្កើត/ចម្លង/កែ/លុបថ្នាក់ តម្រៀបសិស្សតាមអក្ខរក្រមខ្មែរ (ក–អ) ដោយស្វ័យប្រវត្តិ នាំចូលសិស្សពីឯកសារ Excel គំរូ បង្ហាប់រូបថត 3×4 និងនាំចេញបញ្ជីឈ្មោះជា Excel / PDF។
- **បញ្ជីវត្តមាន (Attendance)**៖ កត់វត្តមានប្រចាំខែ (មានគាំទ្រ Ctrl/Arrow, Right-click, ថ្ងៃឈប់សម្រាក ថ្ងៃបុណ្យ) និងរបៀប «ថ្ងៃនេះ» ងាយចុចលើទូរស័ព្ទ រួមទាំងបោះពុម្ព A4 ផ្ដេក និង Excel។
- **បញ្ជីពិន្ទុ (Scores)**៖ បញ្ចូលពិន្ទុប្រចាំខែ និងប្រឡងឆមាស (ទទួលយកលេខខ្មែរ/អារ៉ាប់ `.` ឬ `,` និង Paste ពី Excel ផ្ទាល់) គណនាមធ្យមភាគ និងចំណាត់ថ្នាក់ដោយស្វ័យប្រវត្តិ មើលតារាងស្រង់ពិន្ទុឆមាស/ប្រចាំឆ្នាំ និងនាំចេញ PDF (A4 ២ ទំព័រ ឬ A3 ១ ទំព័រ) និង Excel។
- **កាតសិស្ស (Student Cards)**៖ រចនា និងបោះពុម្ពកាតសិស្សកម្រិត 300 DPI លើក្រដាស A4 គាំទ្រសងខាង (Duplex) និងបន្ទាត់ណែនាំសម្រាប់កាត់ ដោយភ្ជាប់ឈ្មោះសាលា នាយក ខេត្ត/រាជធានី និងឆ្នាំសិក្សាដោយស្វ័យប្រវត្តិ។

## ការរក្សាទុកទិន្នន័យ (Local Storage)

- ទិន្នន័យទាំងអស់ (ព័ត៌មានគ្រូ ថ្នាក់ សិស្ស រូបថត វត្តមាន ពិន្ទុ ថ្ងៃបុណ្យ និងគំរូកាត) ត្រូវបានរក្សាទុកនៅក្នុង **IndexedDB (`KruDeskDB`)** ផ្ទាល់លើឧបករណ៍របស់អ្នក។
- កម្មវិធីស្នើសុំ `navigator.storage.persist()` នៅពេលបើក និងបង្ហាញស្ថានភាពការពារទិន្នន័យនៅក្នុង **ការកំណត់ → Backup & Restore**។
- ពេលបើកប្រើលើកដំបូង ឯកសារពុម្ពអក្សរខ្មែរ និងកម្មវិធីត្រូវបានរក្សាទុកក្នុង Service Worker (PWA) ដើម្បីឱ្យប្រើប្រាស់បានទោះបីគ្មានអ៊ីនធឺណិត (Offline)។

## ការធ្វើសមកាលកម្មលើ Cloud (Cloud Sync), Backup និងការស្ដារទិន្នន័យ

- **គណនី Google តែមួយ ប្រើបានគ្រប់ឧបករណ៍ (ទូរស័ព្ទ & កុំព្យូទ័រ)៖** នៅលើគេហទំព័រផ្លូវការ (`krudesk.vercel.app`) លោកគ្រូអាចចូលប្រើដោយគណនី Google (ក្រោយ Admin អនុញ្ញាត) ដើម្បីឲ្យថ្នាក់ សិស្ស វត្តមាន ពិន្ទុ រូបថត និងការកំណត់សំខាន់ៗ **Sync ដោយស្វ័យប្រវត្តិ** លើគ្រប់ឧបករណ៍ក្នុងរយៈពេលប៉ុន្មានវិនាទី។ ទិន្នន័យរបស់គ្រូម្នាក់ៗឯកជនដាច់ដោយឡែកពីគ្នាទាំងស្រុង។
- **ដំណើរការ Offline ធម្មតា៖** ទោះនៅសាលាគ្មានអ៊ីនធឺណិត ក៏កម្មវិធីនៅតែបើក ហៅឈ្មោះ និងបញ្ចូលពិន្ទុបានធម្មតា (រក្សាទុកក្នុង IndexedDB ប្រចាំគណនី) ហើយនឹងបញ្ជូនឡើង Cloud ដោយស្វ័យប្រវត្តិពេលភ្ជាប់អ៊ីនធឺណិតវិញ។
- **Cloud Backup ប្រចាំថ្ងៃ (ស្វ័យប្រវត្តិ) និងដោយដៃ៖**
  - កម្មវិធីបម្រុងទុកទិន្នន័យទាំងអស់ទៅ Cloud ដោយស្វ័យប្រវត្តិ **១ ដងក្នុង ១ ថ្ងៃ** (រក្សាទុក ១០ ច្បាប់ចុងក្រោយ) ហើយអាចចុច **ការកំណត់ → «បម្រុងទុកឥឡូវ»** ពេលណាក៏បាន។
  - ដើម្បីត្រឡប់ទៅថ្ងៃចាស់វិញ៖ ចូល **ការកំណត់ → «ស្ដារពី Cloud Backup»** រួចជ្រើសថ្ងៃដែលចង់ស្ដារ។ *(ចំណាំ៖ ការស្ដារបែបជំនួសនឹងជំនួសទិន្នន័យលើគ្រប់ឧបករណ៍ដែលចូលគណនីនេះ។)*
- **Backup & Restore ជាឯកសារ `.json` (ក្នុងម៉ាស៊ីន)៖**
  1. **បម្រុងទុក (Backup)**៖ ចូល **ផ្ទាំងដើម** (ចុច «ទាញយក Backup ឥឡូវ») ឬ **ការកំណត់ → Backup & Restore → ទាញយក Backup (.json)**។ ឯកសារ `.json` ផ្ទុកទិន្នន័យទាំងអស់ រួមទាំងរូបថតសិស្ស។
  2. **ស្ដារទិន្នន័យ (Restore)**៖ ចូល **ការកំណត់ → Backup & Restore → ស្ដារពី Backup (.json)** (គាំទ្រទាំងទម្រង់ចាស់ v1 ដល់ v3) រួចជ្រើស **ជំនួសទិន្នន័យទាំងអស់** ឬ **បញ្ចូលបន្ថែម (Merge)**។ ក្រោយស្ដារបែបជំនួស ទិន្នន័យនឹង Sync ទៅគ្រប់ឧបករណ៍ដោយស្វ័យប្រវត្តិ។
- **នាំចូលទិន្នន័យចាស់៖** បើម៉ាស៊ីនមានទិន្នន័យចាស់ (`KruDeskDB`) កម្មវិធីនឹងសួរពេលចូលគណនីដំបូង ដើម្បីចម្លងចូលដោយមិនលុបទិន្នន័យចាស់ឡើយ។ បើទិន្នន័យចាស់នៅលើគេហទំព័រចាស់ (`sithpongrin.github.io/KruDesk/`) សូមទាញយក Backup (`.json`) នៅទីនោះ រួចមកស្ដារលើ `krudesk.vercel.app`។

## វិធីផ្លាស់ទីទៅឧបករណ៍ថ្មី

- **បើប្រើគណនី Google (Cloud Sync)៖** គ្រាន់តែចូលគណនី Google ដដែលលើទូរស័ព្ទ ឬកុំព្យូទ័រថ្មី ទិន្នន័យទាំងអស់នឹងទាញមកដោយស្វ័យប្រវត្តិ។
- **បើប្រើរបៀប Offline សុទ្ធ (គ្មានគណនី)៖** ទាញយក Backup (`.json`) ពីម៉ាស៊ីនចាស់ រួចចុច **«ស្ដារពី Backup»** នៅលើម៉ាស៊ីនថ្មី។

## ការអភិវឌ្ឍ និងដាក់ឱ្យដំណើរការលើ GitHub Pages (Deploy)

### ដំណើរការក្នុងម៉ាស៊ីន (Local Development)

```bash
npm install
npm run dev      # បើក Dev Server (http://localhost:5173/KruDesk/)
npm test         # ដំណើរការតេស្ត Vitest ទាំងអស់
npm run build    # បង្កើតឯកសារផលិតកម្មនៅក្នុង dist/
npm run preview  # សាកល្បងកំណែផលិតកម្ម (http://localhost:4173/KruDesk/)
```

### ដាក់ឱ្យដំណើរការលើ GitHub Pages

គម្រោងនេះកំណត់ `base: '/KruDesk/'` នៅក្នុង `vite.config.ts` និងមាន GitHub Actions workflow នៅ `.github/workflows/deploy.yml`។

1. បង្កើត Repository ឈ្មោះ `KruDesk` នៅលើ GitHub ហើយ Push branch `main` ទៅ GitHub។
2. នៅក្នុង GitHub Repository → **Settings → Pages** ជ្រើស Source ជា **GitHub Actions** (ឬ branch `gh-pages` តាម workflow)។
3. រាល់ពេល Push ទៅ branch `main` GitHub Actions នឹង Build និង Deploy ដោយស្វ័យប្រវត្តិទៅ `https://<username>.github.io/KruDesk/`។
